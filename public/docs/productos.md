# Sitio web para "Casa Capital - Muebles con tecnología"

Sitio web actual: https://www.casacapital.com.ar/
- Desarrollado en WordPress
- Plugins principales:
    - Secure Custom Fields (SCF)
    - Elementor Pro

## ¿Para qué usamos SCF?
- Creación de Post Type personalizado "Productos"
- Creación de grupo de campos personalizados para "Productos"
- Creación de taxonomías
    - Categorías (Category)
    - Líneas (Category)
    - Materiales (Tags)

## Campos para cada producto
- Título
- Slug (url de la página)
- Extracto (texto simple, un párrafo)
- Descripción (texto enriquecido para poder crear sub-títulos, listas, etc)
- Imagen destacada
- Galería de imágenes
- Modelo 3D ¿?
- Descripciones técnicas (Repeater - Título + Texto enriquecido)
- Link a "Ficha técnica"
- Link a "Catálogo de acabados"
- Link personalizado a "Más información" (Por ejemplo WhatsApp)
