# Necesidad

## ¿Qué necesita?

Actualizar su sitio web para:
- Fomentar la presencia web
- Páginas de producto/lineas de producto (catálogos, manuales técnicos, modelos 3D, conctato a wsp martina)
- Formulario de calendly para reservar citas preenciales
- Fortalecer presencia B2B (Beneficios para profesionales: catalogos, asesorias, etc + form de contacto / wsp caro )

## Propuesta de valor

- **Catálogo de productos** en línea auto-administrables
- **Posibilidad de importar modelos 3D** con VR
- **Blog** para contenido y SEO
- **Cápsulas** tipo entradas de blog, para mostrar colaboraciones con otros estudios
- **Multilenguaje** (español, inglés)
- Customizacion personalizada de productos para oficinas
